# Portfolio — Peechara Sathwik

Personal portfolio built with React 18 + Vite, deployed on Vercel.

## Run locally

```
npm ci
npm run dev
```

## Build

```
npm run build
```

Output is written to `dist/`.

## Structure

- `portfolio.jsx` — all UI and content data
- `src/main.jsx` — entry point
- `public/` — static assets
